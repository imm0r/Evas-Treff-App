# Eva's Treff — Galerie

Die App zum privaten Fotoalbum [`imm0r/Evas-Treff`](https://github.com/imm0r/Evas-Treff).

Hier liegt **nur** HTML und JavaScript: kein Foto, kein Zugangscode. Ohne den
Link mit Zugangscode zeigt die Seite nichts an — sie fragt danach und kann
ohne ihn nichts aus dem privaten Repository lesen.

Seiten:

- `index.html` — die Galerie
- `upload.html` — Fotos beisteuern
- `share.html` — Links und QR-Codes bauen (nur für den Organisator)
